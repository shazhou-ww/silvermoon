# Support

Before requesting help:

1. Use the latest Silvermoon release.
2. Read [Getting Started](./docs/getting-started.md) and the
   [Technical Reference](./docs/reference.md).
3. Search existing GitHub issues.

Open a GitHub issue for a reproducible bug or a focused feature request.
Include the Silvermoon, Node.js, Git, and operating-system versions plus the
smallest useful reproduction.

Project support is provided on a best-effort basis. Report security issues
through the [Security Policy](./SECURITY.md), not a public issue.
