# Objective Guide

Language-neutral, URI-keyed Objective definitions bind immutable JSON subjects
and one explicit content language into observable instances. This module owns
Manifest/domain validation, deterministic prerequisite projections, ordered
levels and localized reference pages; it does not own command reports or Git
workflow policy.

`createObjectiveLoader` accepts file resources by default or an explicit resource
resolver and typed check bindings. Loader failures reject, expected instance
creation failures are typed results, and asynchronous probe defects propagate.
No regulator, autonomous loop or portfolio supervisor is included.
