为 current position 增加 owner/check identity，并保持 terminal 与 prerequisite 语义明确。

### I-S02: 规范动态 Problem parameters

让 bundled adapters 返回可渲染的结构化事实，移除仅供旧报告解析的描述拼接。

更新公开类型、whats-next adapter 和 Objective Guide 测试，覆盖有序短路与多 Problem。

类型与 probe 测试证明每个停止点都可解析到 owner/level/check/problems。

Project、repository 和 lifecycle 样例证明路径、revision、branch、state 与 problem
code 等事实保留为参数，并断言 parameters 不携带本地化 report prose。
