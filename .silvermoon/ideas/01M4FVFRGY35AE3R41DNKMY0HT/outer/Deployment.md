# Deployment

## Steps

### D-S01: 发布流程浏览入口

通过仓库文档或等价的可访问制品发布生成的 HTML，使维护者能够浏览当前命令流程与场景结果。

### D-S02: 验证发布制品行为

通过正常发布检查确认已安装 CLI 与仓库中的声明模型和流程浏览结果一致。

## Acceptance criteria

### D-AC01: 维护者可访问当前流程

从发布位置可以打开完整 HTML，并能识别其对应的版本或 commit。

### D-AC02: 发布命令使用声明式流程

已安装制品测试证明 `what's next` 与 `check` 通过声明式解释器产生预期报告，且生成流程资料没有漂移。
