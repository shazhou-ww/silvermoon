# 集中拆分 what's next 多语言文案模板

## 问题

`what's next` 的输出指示与终点文案分散在较大的报告函数中，英文和中文实现相互交错，维护者难以按语言完整审阅措辞，也难以确认所有结论模板是否一致覆盖。

## 结果

把 `what's next` 的每个逻辑文案模板集中到统一目录，并按语言拆分为独立文件，使维护者可以直接浏览某一语言的完整模板集合，后续措辞修改也能形成清晰、局部的审阅差异。

## 边界

- 本轮只整理 `what's next` 的用户可见输出模板，不重构 `check`、流程控制、副作用，也不引入 YAML 或 HTML 流程模型。
- 每个逻辑模板在各支持语言中各有一个独立文件；动态值通过类型化参数传入，模板不读取外部状态或决定流程。
- 首次迁移保持现有报告结构、语言选择和文案语义，后续措辞调整作为可独立审阅的变化进行。

## 验收标准

- `what's next` 的全部用户可见输出指示均可在统一的语言目录中按一个模板一个文件找到，业务编排不再内联成对的多语言长文本。
- 英文与中文模板按稳定标识一一对应，缺失、重复或接口不一致会被自动检查拒绝。
- 现有代表性场景在重构前后产生等价的结构化报告与对应语言文本，并由测试证明。
