# 将 Silvermoon 全面改造为严格类型的 TypeScript 项目

## 意图

将 Silvermoon 的运行时代码、命令行入口、仓库维护脚本和自动化测试统一迁移到
TypeScript，并让静态类型检查成为本地开发、持续集成和发布流程中的强制质量门禁。
迁移后的类型应表达真实领域约束，而不只是让现有 JavaScript 通过编译。

## 背景

项目当前主要由 JavaScript 和 MJS 文件组成，仅为部分公开接口维护独立的
`.d.ts` 文件。实现与声明分离容易产生漂移，跨模块的数据结构、错误路径、事件协议
和命令结果也无法获得完整的编译期验证。随着 Silvermoon 的仓库模型和 Agent
集成持续扩展，弱类型边界会提高重构成本，并使无效状态更容易进入运行时。

## 期望结果

- 仓库中受维护的运行时、CLI、构建与维护脚本、测试及测试辅助代码均以
  TypeScript 源文件表达，不再保留对应的手写 JavaScript、MJS 或独立声明实现。
- TypeScript 配置覆盖所有受维护代码并启用 `strict`，同时启用适合本项目的
  `noUncheckedIndexedAccess`、`exactOptionalPropertyTypes`、
  `useUnknownInCatchVariables`、`noImplicitOverride` 和
  `noFallthroughCasesInSwitch` 等严格检查；类型检查无错误。
- 领域对象、命令输入输出、事件记录、报告投影、配置、文件系统与 Git 交互边界均有
  明确类型。外部输入先以 `unknown` 或等价的未信任类型进入，再经过验证和收窄后使用。
- 项目不依赖无约束的 `any`、宽泛类型断言、`@ts-ignore` 或关闭严格检查来通过迁移；
  确有必要的例外必须范围最小、说明理由，并由自动化检查防止扩散。
- 公开包导出从 TypeScript 实现生成并发布准确的声明文件，声明与实现使用同一事实来源；
  现有导入路径、CLI 命令、退出码、用户可见输出、Schema 和事件协议保持兼容。
- 开发者可通过统一命令完成类型检查、测试和发布级验证，CI 与 npm 打包流程也执行对应
  门禁。发布包仅包含 Node.js 可执行产物、声明、source map 和既有文档资源，不要求
  消费者直接执行 TypeScript。
- 现有测试全部迁移并继续覆盖原有行为，同时为迁移过程中识别出的关键类型边界补充
  编译期或运行时验证。

## 范围

### 范围内

- `src/`、`bin/`、`test/` 中现有 JavaScript/MJS 代码及相关仓库脚本的 TypeScript
  迁移。
- TypeScript 项目配置、模块解析、构建输出、声明与 source map 生成、测试执行器和
  开发脚本的调整。
- `package.json` 的入口、导出、files、scripts 与发布打包流程适配。
- CI、仓库校验层级、npm 包验证和文档中的开发命令更新。
- 为实现严格类型而进行的必要领域类型建模、模块边界整理和小范围重构。
- 对源文件类型、生成产物、公开 API 声明和兼容行为的自动化验证。

### 范围外

- 与类型迁移无关的产品功能、协议或用户体验变更。
- 更换现有包管理器、测试框架、CLI 框架或主要运行时依赖，除非当前工具无法可靠支持
  TypeScript 构建或测试，且替换是完成迁移所必需的。
- 将 Node.js 最低版本扩展到其他 JavaScript 运行时或浏览器。
- 手工改写第三方依赖的类型声明；应优先采用官方类型、社区类型或最小的本地适配边界。
- 提交可由构建稳定复现的临时编译目录；正式发布所需文件仍由打包流程生成并验证。

## 约束

- 遵守现有 ESM 模块语义、Node.js `>=22` 运行时要求、pnpm 锁文件和仓库分层边界。
- 迁移应分批进行，每一批保持可测试；不能通过长期并存两套实现来掩盖未完成迁移。
- 所有外部数据和 I/O 失败必须保留现有显式验证与错误传播语义，不能以静默默认值换取
  类型通过。
- 类型建模应优先使用判别联合、泛型、只读结构、类型守卫和穷尽检查，使非法状态尽量
  无法表示；避免重复定义同一协议结构。
- 生成文件必须可追溯、可复现，并通过打包测试证明 npm 消费者能够使用 CLI、运行时
  导出和声明文件。
- README、维护文档、Silvermoon skill 及其注册副本中直接受影响的命令和路径必须同步
  更新；skill 变更须按仓库流程刷新和验证。
- 整体迁移完成前不得降低既有单元、契约、集成、端到端或发布级验证覆盖范围。
