# Deployment

## Steps

### D-S01: 验证 packaged CLI

从 npm pack 产物运行 page/search，覆盖三种 bundled Objectives 与两种语言。

### D-S02: 发布 Reference 导航说明

在 CLI reference 中记录命令、ID 形式、404 和内部链接行为。

## Acceptance criteria

### D-AC01: 安装产物可查询

隔离安装证明 packaged resources 完整，page/search 输出与 source checkout 一致。

### D-AC02: 文档示例可执行

公开示例覆盖 problem 详情、check 说明和搜索后导航，并通过文档验证。
